# obs-ktotakoyben-vi

Автономный C++/Qt6/HLSL плагин для **OBS Studio 30+** — без зависимости от `obs-plugintemplate`.

## Возможности
- **`ktb — Smart Frame`**: GPU-контейнер на HLSL-шейдере (скругление, свечение, прозрачный фон, встраивание вебки/окон и подсветка при ивентах чата).
- **`ktb — Live Top`**: компактный Топ-5 чатерсов с фирменным черепом без нижней челюсти (`HOT 30M` / `SESSION` / `LIFETIME`).
- **`ktb — Event Popup`**: всплывающие случайные ивенты с редкостями и перехватом ответа зрителя (`+25 XP`).
- **`ktotakoyben Control`**: нативный тёмный Qt6-док управления в интерфейсе OBS.

## Сборка на GitHub (в пустом репозитории)
1. Создайте новый **пустой** репозиторий на GitHub (без шаблонов).
2. Загрузите всё содержимое этого архива в корень репозитория (включая скрытую папку `.github/workflows/build.yml`).
3. Откройте вкладку **Actions** — сборка запустится автоматически и соберёт готовый артефакт `obs-ktotakoyben-vi-windows-x64`.
4. Распакуйте артефакт в папку установки OBS Studio (обычно `C:\Program Files\obs-studio\`).
